# Contributing to Intentional

Thank you for your interest in improving Intentional! Whether you're fixing a bug, adding a new feature, or tweaking UI copy, all contributions are warmly welcomed.

---

## 🛠️ Contribution Workflow

### 1. Discuss in an Issue First
Before writing a major feature or refactoring code:
- Check existing [GitHub Issues](../../issues) to see if the topic is already being discussed.
- If not, open a new issue describing your proposed change or the bug you encountered.
- Discussing ideas first ensures everyone is aligned and prevents duplicate work.

### 2. Fork and Branch
1. Fork the repository to your own GitHub account.
2. Create a descriptive feature branch:
   ```bash
   git checkout -b feature/your-idea-name
   ```

### 3. Vibe Coding & AI Tools
- We openly embrace **vibe coding** and AI-assisted development. Feel free to use coding assistants and LLMs to help author your changes.
- **The Golden Rule:** Please ensure all generated code is reviewed, compiles cleanly without errors via `./gradlew assembleDebug`, and is tested on an emulator or physical device before submitting.

### 4. Submitting a Pull Request
- Reference the related GitHub issue in your PR description (e.g., `Closes #12`).
- Include a brief description of what was changed and screenshots or screen recordings if there are visual UI updates.
- Keep changes modular and focused on one goal per pull request.
